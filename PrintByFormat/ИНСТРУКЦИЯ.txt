ПЕЧАТЬ ПО ФОРМАТУ — установка на новый комп
============================================

Что в папке
  Print_ByFormat.jsx         — печать в один клик
  Print_ByFormat_Setup.jsx   — настройка бумаги на этой точке
  install.bat                — установщик
  L8050_EyePH_Chern.icm      — ICC-профиль (положите сюда сами,
                               взять: C:\Windows\System32\spool\drivers\color
                               на компе, где всё работает)


1. УСТАНОВКА (один раз)
   - Закройте Photoshop.
   - Дважды щёлкните install.bat, на вопрос Windows ответьте «Да».
   - Запустите Photoshop.


2. НАСТРОЙКА (один раз на каждый формат, на каждом компе)
   Скрипт сам понимает, какой шаблон открыт. Но бумага в драйвере
   Epson на каждой точке называется по-своему, поэтому один раз
   нужно показать, какую бумагу брать.

   Для каждого формата — A6, 10x15 (магнит/стикер), A5, A4, A3:
   а) Откройте шаблон этого формата.
   б) File -> Scripts -> Print_ByFormat_Setup
   в) Проверьте, что в сообщении указан правильный формат -> OK.
   г) В окне печати:
        - принтер EPSON L18050,
        - профиль L8050_EyePH_Chern,
        - «Параметры печати» -> бумага для этого формата
          (как она называется на этой точке: «без полосы» и т.д.),
          без полей, тип бумаги, качество -> OK,
   д) Нажмите «Готово».
   В конце появится список: [+] — настроено, [  ] — ещё нет.

   Перенастроить формат — просто сделайте то же самое ещё раз.
   Настройки хранятся в %APPDATA%\PrintByFormat (по файлу на формат).


3. ПЕЧАТЬ
   File -> Scripts -> Print_ByFormat

   Повесить на одну клавишу:
   Редактирование -> Клавиатурные сокращения -> Меню программы ->
   Файл -> Сценарии -> Print_ByFormat -> нажать, например, F12.


Как скрипт понимает формат
   По размеру документа (допуск 0,3 см):
     10x15 -> A6 «без полосы»
     10x15 и в имени файла «стикер», «магнит», «полароид»,
       «поляроид», «паларойд», «поларойд», «телефон»,
       ИЛИ файл лежит в папке, где в названии есть «шаблон»
       -> шаблон 10x15
     A5, A4, A3 -> соответствующая бумага

Если что-то не так
   Откройте Print_ByFormat.jsx в Блокноте, найдите строку
     var DEBUG = false;
   поменяйте на true и сохраните. Теперь скрипт не печатает,
   а показывает, что он увидел (размер, имя, папку) и что выбрал.
   После проверки верните false.

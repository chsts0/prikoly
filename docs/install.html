1

Распакуйте архив

Проводник

Правой кнопкой по архиву → «Извлечь всё…» → в любую обычную папку, например на Рабочий стол. Не запускайте файлы прямо из архива — установщик не найдёт остальные файлы.

2

Запустите УСТАНОВИТЬ.bat

Двойной щелчок
  1. Закройте Photoshop. Если он открыт, установщик попросит его закрыть.
  2. Дважды щёлкните УСТАНОВИТЬ.bat.
    Если синее окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». На вопрос «Разрешить этому приложению вносить изменения?» — «Да».
  3. Откроется окно выбора папки №1 — папка с шаблонами: та, где лежат Полароид новый.psd, Большой магнит.psd и т. д. Выберите её → OK.
  4. Окно №2 — папка «исходники»: куда приходят снимки с камеры. Выберите её → OK.
    Если на этом компе центровка по зрачку не нужна — нажмите «Отмена».
  5. Подождите 2–5 минут: установщик скачает Python и библиотеки, если их нет. В конце будет надпись «Всё установлено без ошибок» → нажмите Enter.

3

Горячие клавиши

Photoshop
  1. Запустите Photoshop. Меню Редактирование → Клавиатурные сокращения… (Edit → Keyboard Shortcuts) или Alt+Shift+Ctrl+K.
  2. Вверху в списке «Сочетания клавиш для» должно стоять «Меню программы» (Application Menus).
  3. Раскройте «Файл». Найдите в нём пункты из таблицы ниже (скрипты — в конце, после «Сценарии»). Щёлкните в колонку «Сочетание клавиш» напротив пункта и нажмите нужную клавишу.
  4. Если Photoshop пишет, что клавиша уже используется — это нормально (F1 — справка, Ctrl+P — печать). Нажмите «Принять»: у старой команды клавиша снимется.
  5. Когда всё назначено — OK.

Порядок для Ctrl+P

Сначала назначьте Ctrl+P на Print_ByFormat (Photoshop снимет его с «Печатать…»), потом — Ctrl+Shift+P на «Печатать…».

Нет пунктов Углы, Целые, save_jpeg, Print_ByFormat

Photoshop был открыт во время установки — перезапустите его. Если всё равно нет — запустите УСТАНОВИТЬ.bat ещё раз и посмотрите, нет ли ошибок.

Совет: сохраните набор клавиш

В том же окне нажмите значок «Сохранить набор» (дискета) — тогда клавиши не потеряются после обновления Photoshop.

Направляющие при открытии

Photoshop

Чтобы при открытии и создании файла сами ставились две направляющие по центру.

  1. Файл → Сценарии → Диспетчер событий сценариев… (File → Scripts → Script Events Manager)
  2. Поставьте галочку «Разрешить событиям запускать сценарии/операции».
  3. Событие Photoshop: «Открыть документ» (Open Document). Сценарий: auto-center-guides → «Добавить».
  4. Событие: «Новый документ» (New Document), сценарий тот же → «Добавить» → «Готово».

Если auto-center-guides нет в списке сценариев — выберите «Обзор…» и укажите файл C:\Program Files\Adobe\Adobe Photoshop 2025\Presets\Scripts\Event Scripts Only\auto-center-guides.jsx.

5

Панель Iris Tools

Photoshop
  1. Меню Плагины → Iris Tools (Plugins). Появится панель.
  2. Перетащите её за вкладку к панели «Слои», чтобы она всегда была под рукой.
  3. Проверьте: нажмите серую кнопку «Магнит» — должен открыться шаблон.

Нет пункта Iris Tools в меню «Плагины» — перезапустите Photoshop. Пишет «Нет файла» или «Папка не читается» — при установке выбрана не та папка шаблонов: запустите УСТАНОВИТЬ.bat ещё раз и выберите правильную.

6

Папка для готовых фото

Photoshop · один раз
  1. Откройте любое фото и нажмите F5.
  2. Первый раз появится окно «Выберите КОРНЕВУЮ папку для готовых фото». Выберите (или создайте кнопкой «Создать папку») главную папку, например Рабочий стол\Готовые → OK.
  3. Впишите пробный номер 0000. Проверьте, что появился файл Готовые\<месяц год>\<ДД.ММ>\4-0000.jpg, и удалите его.

Скрипт запомнит папку навсегда. Сменить потом: зажать Shift и выбрать мышкой Файл → Сценарии → save_jpeg.

Настройка печати

Photoshop · по разу на формат

Бумага в драйвере Epson на каждой точке называется по-своему, поэтому печати один раз показывают, какую бумагу брать для каждого формата. Скрипт запомнит это на этом компьютере, и дальше Ctrl+P будет печатать сам.

Принтер — тот, что стоит на этой точке: EPSON L18050 или EPSON L8050. Пока формат не настроен, Ctrl+P может переспросить перед печатью — это нормально.

Для каждого из 5 форматов

  1. Откройте шаблон этого формата.
  2. Файл → Сценарии → Print_ByFormat_Setup. В сообщении проверьте, что формат назван правильно → OK.
  3. Откроется окно печати Photoshop. Проверьте: принтер — EPSON этой точки (L18050 или L8050), профиль L8050_EyePH_Chern, масштаб 100%.
  4. Нажмите «Параметры печати…» → в окне Epson выберите бумагу из таблицы (как она называется на этой точке), без полей, тип бумаги и качество — как обычно → OK.
  5. Нажмите «Готово». Появится список форматов: [+] — настроен, [  ] — ещё нет.

«Настройка не сохранена»

Значит, окно закрыли не через «Готово». Повторите; если снова не сохраняет — нажмите «Печать» вместо «Готово» (выйдет один пробный лист).

Перенастроить формат

Просто пройдите шаги для него ещё раз — новые настройки заменят старые.

Проверка

Откройте шаблон каждого формата и нажмите Ctrl+P — должно сразу напечататься на нужной бумаге, без окон и вопросов.

Проверка — всё работает?

  • Открыли фото — по центру сами появились две направляющие.
  • Положили снимок в «исходники» — через 5–10 секунд он обрезан по зрачку (JPEG — копия в подпапке centered, RAW открывается в Camera Raw уже обрезанным).
  • F5 сохраняет в Готовые\месяц\день.
  • F1 / F2 раскладывают пару глаз (выделены два слоя).
  • Ctrl+P печатает сразу, Ctrl+Shift+P открывает обычную печать.
  • Панель показывает формат, кнопки шаблонов открывают файлы.

Обновить или переставить

Новую версию файлов или другую папку шаблонов / «исходников» — просто запустите УСТАНОВИТЬ.bat ещё раз. Настройки печати и папка для F5 сохраняются.

Ручная установка

Только если установщик не сработал. Файлы — в папке files архива.

1. Скопировать

2. Поменять пути

Открыть в Блокноте (для файлов в Program Files — Блокнот «от имени администратора»), заменить путь на свой, сохранить.

Папка шаблонов — Plug-ins\IrisToolsPanel\main.js, слэши прямые /:

const TEMPLATES_DIR = "C:/Users/EyePhoto/Desktop/Шаблоны";

Папка «исходники» — C:\Photoshop\center_watcher.py:

WATCH_FOLDER = r"C:\Users\EyePhoto\Desktop\исходники"

Путь к Python (если он не в C:\Python\Python313) — C:\Photoshop\Сторож.bat:

set "PYTHON=C:\Python\Python313\python.exe"

3. Python и автозапуск центровки

  1. Скачать Python 3.13 с python.org. При установке отметить «Add python.exe to PATH».
  2. В командной строке: python -m pip install opencv-python numpy rawpy pillow
  3. Win+R → shell:startup → Enter. Правый клик → Создать → Ярлык. Объект (именно pythonw):
    C:\Python\Python313\pythonw.exe "C:\Photoshop\center_watcher.py" → имя «Центровка зрачка».
